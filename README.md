# Portfolio Risk & Performance Analysis (CAPM)

This project implements the **Capital Asset Pricing Model (CAPM)** to analyze the risk-return profile of a diversified 8-stock portfolio using Python. 

##  Tech Stack
* **Financial Data:** `yfinance` (Real-time stock and Treasury yield data)
* **Statistics:** `statsmodels` (OLS Regression Engine)
* **Data Manipulation:** `pandas`, `numpy`
* **Visualization:** `matplotlib`

##  Key Results (2019 - Present)
The analysis was performed on an equal-weighted portfolio consisting of: **NVDA, XOM, PG, JPM, KO, JNJ, AMZN, and META.**
* **Portfolio Beta: 0.96** (The portfolio is slightly more conservative than the market).
* **Portfolio Alpha: 4.40%** (The annualized outperformance generated by stock selection).

### Individual Stock Highlights
* **High-Beta Leader:** **NVDA (Beta: 1.82)** showed the highest sensitivity to market moves.
* **The Alpha King:** **NVDA** also generated a massive **30.45% Alpha**, significantly contributing to total portfolio performance.
* **Defensive Anchors:** **JNJ (Beta: 0.42)** and **PG (Beta: 0.49)** provided stability, effectively lowering the overall portfolio risk.

##  Methodology
1. **Data Acquisition:** Downloads historical adjusted closing prices for tickers and the 10-Year Treasury Yield (^TNX) as the risk-free rate.
2. **Feature Engineering:** Converts prices to daily log returns and calculates excess returns
3. **Regression Modeling:** Runs OLS regression for each asset against the market proxy (SPY).
4. **Portfolio Aggregation:** Calculates weighted average metrics to determine the "Team" performance.
